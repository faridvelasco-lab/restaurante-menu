# Restaurante Sabor Caleño

Sitio web de un restaurante con menú de platos típicos del Valle del Cauca.
Proyecto del curso **Desarrollo de Software I** - Universidad del Valle, Sede Norte.

## Autor
- [Farid santiago otero velasco]
- [202554040]

## Descripción
Página web estática con dos páginas de contenido conectadas entre sí
mediante un menú de navegación, más una página de inicio.

## Estructura del proyecto
- `index.html`: página de inicio
- `pagina1.html`: platos fuertes
- `pagina2.html`: bebidas y postres
- `estilos.css`: estilos compartidos por todas las páginas
- `README.md`: documentación del proyecto

## Tecnologías
- HTML5
- CSS3
- Git y GitHub

## Cómo ejecutarlo
1. Clona el repositorio.
2. Abre `index.html` en tu navegador.
